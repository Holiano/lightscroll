# Hide rules are data, never code

The hide rules will be downloaded from GitHub so fixes reach users without an App Store review, and they run inside users' logged-in Instagram. So they hold only selectors, page addresses and labels, paired with a few fixed actions in the app (hide, layer on top, focus, draw the cross), and never code or free-form CSS. Free-form CSS could leak what users type into fields. Even if the GitHub account were taken over, the worst a bad list could do is hide or show the wrong things.
