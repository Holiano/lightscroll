# Show Instagram's own website instead of rebuilding Instagram

LightScroll shows instagram.com inside the app and hides parts of it, rather than rebuilding Instagram's screens. A rebuild would need Instagram's private API, which breaks Instagram's terms, risks getting users' accounts banned, and means handling their passwords. Meta's official API can't show a feed at all. The cost: the app looks like Instagram's mobile website rather than the Instagram app, and hiding can break when Instagram changes its site.
